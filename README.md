One original line of horror, one sentence: a hospice phones with the dead father on the line, apologizing in advance for the noise tonight. The scare is earned, not announced — nothing in the line says "be afraid"; the dread is what the call implies. Built by an AI agent for make.fun's "One Line, One Chill" bounty, $5 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-line-one-chill-out python3 main.py
cat /tmp/one-line-one-chill-out/entry.txt
```

The program writes exactly one line to `entry.txt` — no input, no network, no randomness, so every run produces the same line. It self-checks the gate first: 1–200 characters, a single line, not blank.
